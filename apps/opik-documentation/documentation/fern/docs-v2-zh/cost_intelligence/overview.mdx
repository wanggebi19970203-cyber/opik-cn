你的提供商账单告诉你花了**多少** token，却没有告诉你这些 token 花在**什么**上面。

与任何其他 LLM 工作负载相比，这一差距在编码智能体身上影响更大。一次 Claude Code 请求就携带着数千 token 的系统提示词、每个已启用 MCP 服务器的工具 schema、记忆文件、技能列表、子智能体定义，以及累积的对话记录——所有这些都发生在开发者输入第一个字符之前。一个扁平化的 token 计数无法告诉你：一次昂贵的会话中有 70% 是框架开销，也无法告诉你某个没人使用的 MCP 服务器出现在每一次请求中。

Cost Intelligence 填补了这一差距。它捕获线路上的每一次编码智能体 API 调用，将这些字节归因到成本桶，并为你提供真正可操作的每用户、每会话、每仓库视图，同时还提供了配套的策略控制。

<Note>
  Cost Intelligence 是一项企业版功能，需要工作区管理员权限。如果你的工作区中看不到它，请联系你的 Comet 客户团队。
</Note>

## 你的 token 实际去向

每一次 Claude Code 调用都被拆解为驱动它的各个部分：系统提示词、工具 schema、MCP 服务器、记忆文件、技能、子智能体，以及夹杂在其中的开发者真正输入的内容。

<Frame>
  <img src="/img/v2/cost-intelligence/home_page.png" alt="Claude Code token 支出按成本桶拆解" />
</Frame>

对大多数团队来说，令人意外的是这个比例。你的开发者所写的提示词只是你所付费的一小部分；其余的是框架开销，其中大部分是没有人选择、也没有人使用的配置。

这正是关键所在。一旦你能看到这些驱动因素，就可以移除那些不产生任何价值的部分。在实践中，这意味着**支出降低 15% 到 30%，而你的开发者能做的事情没有任何变化**，因为被削减的是未使用的 MCP 服务器、废弃的技能和失控的工具输出，而不是工作本身。
