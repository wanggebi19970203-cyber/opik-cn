Cost Intelligence 位于你的开发者编码智能体流量的路径上，因此你完全有理由想得到"什么会离开机器"这一问题的精确答案。本页就是逐字段给出的答案。

简短版本：**只上报计数、成本和结构性元数据。** 提示词和响应内容不会被收集，除非有人明确开启它，而组织可以阻止这种情况永远发生。

## 收集了什么

下面每一节都列出了字段，并包含一个可展开的真实负载示例，展示的是内容捕获**关闭**（默认状态）时的情况。值仅为示例。

### 每个会话

| 字段 | 含义 |
| --- | --- |
| 会话 ID | 一次编码会话的标识符 |
| 工作目录 | 会话运行所在的路径 |
| 项目名称 | 解析出的项目标签 |
| 用户身份 | 邮箱、用户名、显示名称、组织 |
| 计费归因 | 套餐、席位层级、计费模式 |
| Git 仓库 | 远程 URL、分支、提交 SHA |
| 提交统计 | 每一轮的文件数和行数。**无 diff、无文件名** |

### 每次调用

| 字段 | 含义 |
| --- | --- |
| 模型 | 为该调用提供服务的模型 |
| 请求 ID | 提供商自己的请求标识符 |
| Token 计数 | 输入、输出、缓存创建、缓存读取、按层级的缓存拆分。**逐字读取自提供商的 usage 负载**，从不估算 |
| 服务层级 | Standard、batch 或 priority |
| 模型配置 | Effort 级别、思考模式、token 限制、上下文管理 |
| 错误 | 状态码和重试次数。**无错误正文** |
| 调用结构 | 触发器、轮次和 trace 标识符、父级链接 |

### 每个内容块

请求或响应中每个可分类区域对应一行。正是这一点使成本归因成为可能。

| 字段 | 含义 |
| --- | --- |
| 位置 | 该块在请求结构中所处的位置（一个线路坐标，而非文件路径） |
| 成本桶 | 它属于约 20 个类别中的哪一个 |
| 大小 | 字符数或字节数 |
| 内容哈希 | 该块内容的单向哈希 |
| 媒体类型 | 用于二进制块（图片、PDF） |
| 工具 / 资源名称 | 工具、MCP 服务器、技能或智能体的**名称**。**不含参数或结果** |
| 缓存状态 | 该块是缓存读取、写入还是全新的 |
| 正文 | **仅在明确启用内容捕获时才存在** |

</Note>

### 从不收集

| | |
| --- | --- |
| 提示词和响应文本 | 除非明确启用内容捕获 |
| 思考文本 | 除非明确启用内容捕获 |
| 工具参数和结果 | 仅名称 |
| 源文件内容、diff、文件名 | 仅计数 |
| 编码智能体对话记录内容 | 仅路径。该文件从未被读取 |
| API 密钥和凭据 | 在捕获时即被脱敏，早于任何写入 |
| 请求和响应头 | 不发送 |

## 内容捕获开关

有一个设置决定任何提示词或响应文本是否会离开设备。

| | |
| --- | --- |
| **默认** | 关闭。无需任何配置即可获得隐私姿态 |
| **设置位置** | `CIPX_CAPTURE_CONTENT`，通过托管设置或 MDM 下发 |
| **组织否决权** | 将其显式设为 `false` 是硬否决。任何单个用户都无法覆盖它 |
| **可审计** | 每个会话都会记录该决定，因此你可以查询哪些会话（如果有的话）上报了内容 |

<Warning>
  如果你的组织没有固定该值，单个开发者可以自行选择开启。沉默不是否决。对于对 IP 敏感的团队，请将
  `CIPX_CAPTURE_CONTENT` 显式设为 `false`，而不是保持未设置。
</Warning>

## 策略同步在设备上写入什么

应用[成本策略](/cost-intelligence/roll-out-cost-policies)只会写入 `~/.claude/settings.json` 和 `~/.codex/config.toml` 中的托管策略键；每个文件的其余部分属于开发者自己。无法解析的设置文件会被原样保留，失败只会出现在本地日志和错误遥测中。

## 数据去向

| 目的地 | 用途 | 控制 |
| --- | --- | --- |
| 你的模型提供商或网关 | 原始 API 调用，逐字节原样转发 | 固有的 |
| 你的 Opik 工作区 | 上述负载 | 自托管 Opik 可将这些数据保留在你自己的基础设施内 |
| 错误遥测 | 崩溃和错误报告，含堆栈跟踪。无请求或响应正文 | 将 `CIPX_SENTRY` 设为 `off` 可禁用 |
| 插件分发 | 插件自动更新 | 禁用市场自动更新 |

## 安全

**传输中。** 编码智能体仅通过回环接口与代理通信，因此该流量从不经过网络。代理向模型提供商发起自己的 TLS 连接，并进行完整的证书校验，通过 HTTPS 发送到 Opik。代理、管理端和查看端监听器拒绝绑定除 `127.0.0.1` 之外的任何地址，若绑定公网地址则启动失败。

**凭据。** 授权头在捕获时即被脱敏，早于任何写入磁盘的操作。原始头原样转发到上游，因此代理对认证是透明的，从不重写调用方的凭据。

**落盘。** 本地暂存位于 `~/.opik-cipx/`，目录权限为 `0700`，文件权限为 `0600`。它是一个缓冲区，而非归档，并且受总磁盘上限和保留窗口约束，以先触发者为准。

<Warning>
  内容捕获设置管控的是**上报给 Opik** 的内容。它不管控本地缓冲区：完整的请求和响应字节无论如何都会写入本地暂存，因为管线需要从它们重新推导成本归因。这些数据从不离开机器、不可被他人读取，并且会按上述上限自动过期，但如果你的基线要求更短的窗口，请在部署配置中调低
  `raw_retention_days` 和 `disk_cap_bytes`。
</Warning>

**TLS 拦截。** 推荐的插件推广方案（[托管设置](/cost-intelligence/install/managed-settings)和 [MDM](/cost-intelligence/install/mdm)）**不会**终止、解密或检查 TLS，也不安装任何证书。可选的 [macOS 应用](/cost-intelligence/install/macos-app)确实会在本地终止 TLS，使用按设备生成的证书颁发机构，其私钥由硬件保护且不可导出，并约束到模型提供商的主机名。
